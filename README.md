# AmazingHand Setup

[Pollen Robotics AmazingHand](https://github.com/pollen-robotics/AmazingHand) — 저비용 오픈소스 4손가락 로봇 손(8x Feetech SCS0009 서보) — 을 macOS에서 조립·제어하기 위한 스크립트와 정리 노트.

## 하드웨어 구성

- 손가락 4개 × 서보 2개 = 서보 8개 (Feetech SCS0009)
- USB-TTL 시리얼 버스 드라이버 (macOS에서 `/dev/cu.usbmodem...`로 인식됨)
- 외부 5V DC 전원

## 빠른 시작

```bash
python3 -m pip install rustypot numpy

# 포트 확인 (드라이버 보드 연결 후)
ls /dev/cu.*
# 아래 스크립트들 안의 PORT 변수를 실제 값으로 맞출 것

# 손가락 4개 동시 데모
python3 AmazingHand_Demo_All.py
```

## 스크립트

| 파일 | 용도 |
|---|---|
| `scan_ids.py` | 버스에 연결된 서보의 ID를 스캔. 같은 ID에 값이 2개 이상 섞이면 충돌(서보 2개 이상)로 판단 |
| `set_id.py` | `python3 set_id.py <현재ID> <바꿀ID>` — 서보 1개를 지정 ID로 변경 (EEPROM 잠금 해제 포함) |
| `assign.py` | `python3 assign.py <바꿀ID>` — 버스에 연결된 서보를 자동 감지해서 지정 ID로 변경 (스캔+변경 한 번에) |
| `AmazingHand_FingerTest.py` | 손가락 1개(서보 2개) 열기/닫기 테스트 |
| `AmazingHand_Demo_All.py` | 손가락 4개(서보 8개) 전체 열기/닫기 데모. 종료(Ctrl+C) 시 자동으로 토크 해제 |

## 서보 ID 설정 절차

여러 서보가 같은 버스에 물리면 대부분 공장 기본 ID(1)를 공유해서 충돌합니다. **한 번에 서보 1개만** 연결한 상태로 ID를 하나씩 지정해야 합니다.

1. 서보 1개만 버스에 연결
2. `python3 scan_ids.py 1 2 3 4 5 6 7 8` 로 현재 ID 확인
3. `python3 set_id.py <현재ID> <원하는ID>` (또는 `assign.py <원하는ID>`)로 변경
4. 서보 교체, 2~3 반복
5. 전부 연결한 뒤 다시 스캔해서 ID마다 값이 하나씩만 나오는지 (충돌 없는지) 확인

> EEPROM 잠금(`write_lock`)을 풀고 쓰지 않으면, 전원을 껐다 켜는 순간 ID가 공장 기본값으로 되돌아가는 경우가 있었습니다. `set_id.py`/`assign.py`는 이 문제를 자동으로 처리합니다.

## 겪었던 문제와 원인

- **ID 충돌**: 서보 2개 이상이 같은 ID를 가진 채 연결되면 응답이 깨지거나(`Checksum error`/`Parsing error`) 여러 값이 섞여 나옴. 반드시 1개씩 격리해서 설정.
- **ID가 전원 재연결 후 초기화됨**: EEPROM 잠금을 안 풀고 쓰면 발생. `write_lock(id, False)` 후 `write_id` 하면 해결.
- **토크 켤 때 서보가 튐**: 서보는 토크를 켜는 순간 마지막 목표각도로 이동함. 토크를 켜기 전에 현재 위치를 읽어서 그 값을 목표각도로 먼저 써주면 안 튐 (`enable_torque_without_jump`).
- **일부 관절이 범위 끝에서 잘 안 움직임**: `max_angle_limit` 레지스터가 서보 위치 표현 범위(약 -150°~150°)보다 더 좁게 설정된 경우가 있었음. 필요 시 `write_max_angle_limit`으로 조정.
- **서보마다 중립 각도가 다름(혼 조립 위치)**: 손가락1(ID 1,2)은 혼이 0도 근처로 조립돼서 ±90/±30 범위를 그대로 씀. 나머지 손가락은 혼이 140도대에 조립돼있어서 대칭 동작이 안 됐고, **혼을 서보 축에서 빼서 축을 0도로 맞춘 상태로 재조립**해서 해결함 (아래 방법).
- **종료 후에도 서보가 계속 힘을 씀**: 스크립트 종료 시 토크를 꺼주지 않으면, 손가락 기구의 스프링 장력에 맞서 서보가 계속 위치를 유지하려고 미세하게 움직임(정상 동작이지만 불필요). `AmazingHand_Demo_All.py`는 종료 시 자동으로 전체 토크를 끔.

## 서보 중립각(혼) 재조립 방법

혼(horn)은 서보 축에 나사로 고정된 부품으로, 어느 스플라인 홈에 끼우느냐에 따라 "서보값 0도가 가리키는 실제 방향"이 달라집니다.

1. 혼 고정 나사를 풀어 혼(+링크)을 축에서 분리
2. 서보 축만 0도로 회전시키는 명령 전송 (혼이 빠져있어서 손가락은 안 움직이고 축만 돎)
3. 축이 0도를 유지한 상태에서, 손가락이 원하는 중립 자세(다른 손가락과 정렬된 편 자세)가 되도록 혼을 끼우고 나사 조임

이후 그 서보는 중립=0도 기준으로 다른 정상 관절과 동일한 방식(±90/±30 미러링)으로 제어 가능.

## 현재 서보별 각도 설정 (`AmazingHand_Demo_All.py`)

| 손가락 | ID 쌍 | 열림(도) | 닫힘(도) | 비고 |
|---|---|---|---|---|
| A | 1, 2 | -30 / 30 | 90 / -90 | 최초 캘리브레이션, 중립 0 |
| B | 3, 4 | 144 / -30 | 54 / 90 | |
| C | 5, 6 | 141 / -30 | 24 / 118 | 다른 손가락보다 덜 굽혀져서 폭을 넓힘 |
| D | 7, 8 | 144 / -30 | 54 / 90 | |

값은 실측 기반이라 서보 교체·재조립 시 다시 캘리브레이션 필요.
